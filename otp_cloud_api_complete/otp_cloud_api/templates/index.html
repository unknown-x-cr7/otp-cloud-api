Two endpoints. One workflow.

v1
POST/v1/otp/sendSend a code
curl -X POST https://YOUR-DOMAIN/v1/otp/send \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"phone":"+8801XXXXXXXXX"}'
POST/v1/otp/verifyVerify a code
curl -X POST https://YOUR-DOMAIN/v1/otp/verify \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"phone":"+8801XXXXXXXXX","code":"123456"}'

API keys are issued by the service operator and must be kept on your server, never embedded in a public browser app. Only send OTPs to people who requested verification.
